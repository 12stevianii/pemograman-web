Program Studi S1 Teknik Informatika

Program Studi S1 Teknik Informatika dirancang untuk membekali mahasiswa dengan pengetahuan teoritis dan praktis dalam pengembangan perangkat lunak, algoritma, kecerdasan buatan, pemrograman, serta sistem informasi modern. Program ini menyiapkan lulusan yang mampu bersaing di era digital dan industri 4.0.

Visi

Menjadi program studi unggulan dalam bidang rekayasa perangkat lunak dan teknologi informasi, yang berkontribusi dalam pembangunan masyarakat digital yang cerdas dan inovatif.

Misi

  • Menyelenggarakan pendidikan informatika yang adaptif terhadap perkembangan teknologi global.
  • Mendorong riset aplikatif dalam bidang software engineering, AI, dan data science.
  • Menjalin kemitraan strategis dengan industri dan institusi pendidikan tinggi lainnya.

Kompetensi Lulusan

  • Software Engineer dan Full Stack Developer
  • Spesialis Data Science dan Machine Learning
  • Analisis Sistem dan Arsitek Aplikasi
  • Pengembang Game dan Multimedia Interaktif

Mata Kuliah Inti

  • Algoritma dan Struktur Data
  • Pemrograman Berorientasi Objek
  • Basis Data
  • Kecerdasan Buatan
  • Rekayasa Perangkat Lunak
  • Sistem Operasi
  • Jaringan Komputer

Akreditasi dan Statistik

  • Akreditasi: B
  • Jumlah Mahasiswa: 580
  • Dosen Tetap: 15

Prospek Karier

  • Programmer / Software Developer
  • Data Analyst / Data Scientist
  • Game Developer
  • System Analyst
  • Peneliti Teknologi Informasi
